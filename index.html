02 / AUDIO-LANGUAGE REASONING

TextBridge

Built audio-grounded semantic retrieval with Qwen2.5-Omni and Sentence-BERT. A hybrid of sound labels and generated captions achieved a reported 83.6% top-1 accuracy across 3,740 queries in 10 Matterport3D scenes, compared with 80.9% for labels alone.

PAPER 01 ACCEPTED · ICCCMLA 2026

CapNav: Description-First Indoor Navigation with Instance-Level Semantic Maps

Second author · IEEE 8th International Conference on Cybernetics, Cognition and Machine Learning Applications · Paper ID #009823.

Built around instance-level semantic maps: Detic detections and LSeg visual features are assembled into tracked 3D objects; object captions and BGE-M3 semantic retrieval connect natural-language descriptions to navigation targets, with A* for path planning.

Detic / LSeg3D object trackingGemini captioningBGE-M3A* planning
